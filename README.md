# Accessible Components

Tabs, disclosure, modal dialog, and toast built to WAI-ARIA Authoring Practices with full keyboard support.

**Live demo:** `https://YOUR-USERNAME.github.io/a11y-components/` (after enabling GitHub Pages)

## Features
- Tabs with roving tabindex and arrow/Home/End keys
- Disclosure using aria-expanded
- Modal with focus trap, Escape to close, focus return
- Toast announced through an aria-live region
- Respects prefers-reduced-motion and dark mode

## Run locally
No build step. Open `index.html` in a browser.
