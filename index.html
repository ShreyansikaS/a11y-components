Accessible Components

Four UI patterns built with semantic HTML, ARIA, and full keyboard support. Try them with Tab, arrow keys, Enter, and Escape.

Tabs

Use Left and Right arrows to move between tabs; Home and End jump to the first and last.

Tab panels are focusable so keyboard users can reach their content.

Only the active tab is in the tab order (roving tabindex).

Disclosure

Only one item in a composite widget has tabindex 0. Arrow keys move that focus, so Tab skips past the whole widget.
